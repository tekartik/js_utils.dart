# js_utils.dart

JavaScript utilities for Dart web code (browser and node):

* [js_utils_interop](js_utils_interop) (`tekartik_js_utils_interop`): helpers
  on top of `dart:js_interop` (dart2js and dart2wasm). Use this one.
* [js_utils](js_utils) (`tekartik_js_utils`): deprecated `package:js` version,
  dart2js only, kept for old code.
